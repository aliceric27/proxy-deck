ProxyDesk bundles the following third-party components.

sing-box 1.14.2
  License: GNU General Public License v3.0 or later
  Source: https://github.com/SagerNet/sing-box/tree/v1.14.2
  Distributed as the unmodified official Windows release binary (sing-box.exe),
  run as a separate process. ProxyDesk does not link against it.

Rule sets (resources/rulesets: geosite, geoip, acl .srs files)
  A snapshot (2026-10-06) of Karing's rule sets:
  https://github.com/KaringX/karing-ruleset (branch `sing`)
  - geosite / geoip: from MetaCubeX/meta-rules-dat (GPL-3.0),
    https://github.com/MetaCubeX/meta-rules-dat, built on
    v2fly/domain-list-community (MIT) and public GeoIP data.
  - acl: from ACL4SSR (CC BY-SA 4.0), https://github.com/ACL4SSR/ACL4SSR
  Distributed unmodified.
